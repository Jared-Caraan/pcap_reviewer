## Welcome to Python Essentials 2

The course picks up where _Python Essentials 1_ leaves off. Its main goal is to teach you the skills related to the more **advanced aspects of Python programming**, as well as with **general coding techniques** and **object-oriented programming** (OOP).

The course is recommended for aspiring developers who are interested in pursuing careers connected with **Software Development**, **Security**, **Networking**, and the **Internet of Things** (IoT).
